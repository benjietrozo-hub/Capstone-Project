## 📤 How to Submit

### Email Submission:
1. Fill out this form
2. Get department head signature (if required)
3. Email to: **admin@olineims.com**
4. Subject: "Distribution List Request - [Your Name]"

### In-Person Submission:
1. Print and fill out this form
2. Get necessary signatures
3. Submit to IT/Admin Office

### Online Submission:
1. Login to Online IMS
2. Go to "Distribution Groups"
3. Click "Request New List"
4. Fill out the online form

---

## ⏱️ What Happens Next?

1. **Within 2 days** - We'll review your request
2. **Within 5 days** - You'll get approval/denial notification
3. **Within 7 days** - List will be created and ready to use

You'll receive email updates at each step!

---

## 💡 Tips for a Successful Request

✅ **Be Specific** - Clearly explain why you need the list
✅ **Be Accurate** - Double-check member information
✅ **Be Realistic** - Only request lists you'll actually use
✅ **Get Approval** - Ensure department head signs if required

**Common Questions:**

**Q: Can I create a list myself?**
A: Yes! Teachers can create personal lists directly in the system. This form is for official department/school-wide lists.

**Q: How many members can I add?**
A: No limit! Add as many as needed.

**Q: Can I change the list later?**
A: Yes, you can add/remove members anytime if you're the list manager.
