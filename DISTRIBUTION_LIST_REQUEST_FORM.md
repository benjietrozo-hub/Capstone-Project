## 📤 Submission Instructions

### How to Submit:

**Option 1: Online Submission**
1. Fill out this form digitally
2. Save as PDF
3. Email to: admin@olineims.com
4. Subject: "Distribution List Request - [Your Name]"

**Option 2: Physical Submission**
1. Print this form
2. Fill out completely
3. Get necessary signatures
4. Submit to IT/Admin Office

**Option 3: Through System**
1. Login to Online IMS
2. Go to "Distribution Groups"
3. Click "Request New Group"
4. Fill out online form
5. Submit for approval

## ❓ Frequently Asked Questions

**Q: How long does it take to create a distribution list?**
A: Typically 6-10 business days from submission to implementation.

**Q: Can I create my own distribution list without approval?**
A: Yes, teachers can create "User Lists" directly in the system. This form is for "System Lists" that require admin approval.

**Q: Can I modify the list after it's created?**
A: Yes, if you're designated as the list manager. System lists require admin approval for changes.

**Q: Is there a limit to the number of members?**
A: No, but very large lists (100+ members) may require additional review.

**Q: Can I request multiple distribution lists at once?**
A: Yes, submit a separate form for each list.

**Q: What if my request is denied?**
A: You'll receive feedback explaining the reason. You can revise and resubmit.
